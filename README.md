# Daily Routine Tracker

A private, single-site WordPress plugin to manage, run, and track hour-by-hour daily routines with task-level time tracking and reporting.

## Features

- **Today View:** Highlights current time slots automatically, tracks actual vs. scheduled time, supports granular sub-tasks with timers and billable toggles.
- **Routine Editor:** Add, edit, or adjust recurring time blocks across weekday and weekend routines.
- **Reports Dashboard:** Detailed completion rates, tracked time summaries, category breakdowns, and billable time tables.

## Requirements

- **WordPress:** 5.8+
- **PHP:** 7.4+
- **License:** GPLv2 or later
